# Toy OS project
My own OS kernel. Utilizes GRUB as the bootloader. 
## Current features
-   GDT
-   IDT
-   ISR
-   IRQ
-   i8259A PIC driver
-   PS/2 keyboard driver
-   Memory detection with help from GRUB
## Upcoming features
-   Memory management
-   Process scheduling
-   NIC driver
-   Shell
-   System API
-   USB stack
-   VGA driver
-   VFS
